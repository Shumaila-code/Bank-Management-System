# 🏦 Bank Management System

A simple **Bank Management System** developed in Python using Lists, Dictionaries, Loops, and Conditional Statements. This project allows users to perform basic banking operations through a console-based interface.

## 🚀 Features

- ✅ Create Account
- ✅ View All Accounts
- ✅ Search Account
- ✅ Deposit Money
- ✅ Withdraw Money
- ✅ Check Account Balance
- ✅ Delete Account
- ✅ Delete Confirmation (Yes/No)
- ✅ Exit Program

## 🛠️ Technologies Used

- Python 3
- Lists
- Dictionaries
- Loops
- Conditional Statements
